# lecture-script-matcher — UI 변경사항

인쇄물(브라우저 → PDF 저장) 중심으로 프론트엔드를 손봤습니다.
백엔드는 한 군데(`rerun_notes`)만 건드렸고, 매칭·교정·전사 로직은 전혀 수정하지 않았습니다.

동봉한 파일들을 기존 코드에 **덮어쓰기** 하면 됩니다. 경로는 그대로 유지돼 있어요.

---

## 왜 이렇게 했는지

기존 다운로드 PDF는 `pdf_export.py`가 PyMuPDF로 좌표에 글자를 직접 찍는 방식이라
볼드·서체 변경·자간 조정이 불가능했습니다. 어떤 상수를 만져도 타이포그래피에 한계가 명확해서,
**웹 화면에 인쇄 전용 레이아웃을 만들고 브라우저 인쇄로 PDF를 뽑는** 방식으로 갔습니다.

`pdf_export.py`는 손대지 않았으니 기존 PDF 다운로드 버튼도 그대로 동작합니다.

## 새 파일

### `frontend/components/PrintView.tsx`

화면에는 안 보이고 인쇄할 때만 나타나는 레이아웃입니다. 결과 페이지에서
`<div className="hidden print:block">` 안에 렌더링됩니다.

구성:

```
표지          차시 / 제목 / 교수님 이름 (결과 페이지에서 입력받음)
슬라이드 n장   가로 A4 한 장 = 슬라이드 한 장
                 왼쪽 60%  강의록 이미지 + 그 아래 핵심 정리
                 오른쪽 40% 교수님 설명
부록          정리본(슬라이드별 핵심정리 모음) → 전체 정리본 → 퀴즈 → 퀴즈 정답
```

스크립트 분량에 따라 본문 글자가 11px → 10px → 9px로 자동으로 조여집니다
(`DENSITY` 상수). 가로 한 장을 넘기지 않게 하려는 장치입니다.

부록의 `SummaryDigest`는 이미 있는 페이지별 `summary`만 재조합하므로 **추가 LLM 호출이 없습니다.**

## 수정한 파일

### `frontend/app/globals.css`
`@media print` 블록 추가. `@page { size: A4 landscape; margin: 12mm }`,
`.print-slide { height: 174mm; overflow: hidden }`.

높이를 인쇄 가능 높이(186mm)보다 12mm 낮게 잡은 이유는, 1mm라도 넘치면
매 장 뒤에 빈 페이지가 딸려 나오기 때문입니다.

### `frontend/app/layout.tsx` · `tailwind.config.ts`
본문용 한글 명조 `Noto Serif KR` 추가 (`font-reading`).
기존 Fraunces / Source Sans는 latin subset만 담고 있어 한글이 시스템 폰트로 폴백되고 있었습니다.

폰트 스택을 `Helvetica → Noto Serif KR` 순으로 짜서 **영문·숫자는 Helvetica, 한글은 명조**로
갈라지게 했습니다. 브라우저가 글리프 있는 첫 폰트를 쓰는 성질을 이용한 것입니다.

CJK 폰트는 용량이 커서 `subsets` 대신 `preload: false`를 써야 합니다.

### `frontend/lib/themes.ts`
6종 테마의 배경·글씨색 값을 교체했습니다. 구조는 그대로입니다.

### `frontend/app/result/[jobId]/page.tsx`
- "인쇄 · PDF로 저장" 버튼 (`window.print()`)
- "인쇄 설정" 블록 — 표지용 차시·제목·교수님 입력란 + 테마 팔레트
- 화면용 UI에 `no-print` 클래스 부여
- **테마 선택값을 화면에도 연결.** 기존에는 이 값이 백엔드 PDF 다운로드 URL에만
  붙고 화면에는 반영되지 않았습니다.

### `frontend/components/ScriptPanel.tsx`
- **`score: 0.87` 디버그 표시 제거** (개발자용 숫자가 사용자에게 그대로 노출되고 있었습니다)
- 하이라이트를 빨간 글씨 → 노란 배경으로
- 타임스탬프를 본문보다 작고 옅게
- 본문에 박혀 있던 `text-slate-900` 제거 — 테마 글씨색을 덮고 있었습니다

### `frontend/components/SummaryPanel.tsx` · `PdfPreview.tsx`
행간·항목 간격 확대, 섹션 레이블 통일, 색상 상속 처리.

### `frontend/components/UploadPanel.tsx` · `SettingsSidebar.tsx` · `app/batch/page.tsx` · `app/page.tsx`
- 강조색 `rgb(111,134,168)` → `#C4A55F` (금색) 전체 치환
- 홈 화면을 인쇄물과 같은 톤으로 (명조 제목, 배경 `#FAFAF7`)
- 업로드 아이콘 3종을 채워진 형태 → 얇은 선(1.4px)으로 다시 그림

## 백엔드 — `backend/app/main.py` 한 군데

`rerun_notes()`에서 페이지를 갱신하는 부분입니다.

기존에는 재생성할 때마다 `summary`와 `quiz`를 새 값으로 **덮어썼습니다.**
`note_mode`는 `summary` / `quiz` / `full_note` 중 하나만 생성하므로,
퀴즈를 만들면 기존 요약이 빈 배열로 날아갔습니다.

이번에 만든 값이 없으면 기존 값을 유지하도록 바꿨습니다:

```python
result["pages"] = [
    {
        **p,
        "summary": summaries[i] or p.get("summary") or [],
        "quiz": quizzes[i] or p.get("quiz") or [],
    }
    for i, p in enumerate(result["pages"])
]
result["lecture_document"] = (
    lecture_document
    if lecture_document.get("title")
    else result.get("lecture_document")
)
```

이제 요약 → 퀴즈 → 전체 정리본 순으로 여러 번 돌리면 셋을 함께 가질 수 있고,
인쇄물 부록에 전부 실립니다.

## 쓰는 법

1. 백엔드·프론트엔드 실행 (기존과 동일)
2. 결과 화면 → **슬라이드별 보기** 탭
3. **인쇄 설정**에서 차시·제목·교수님·테마 선택
4. 오른쪽 위 **인쇄 · PDF로 저장**

**Chrome을 쓰세요.** Safari는 `@page { size: landscape }`를 무시해서 세로로 나옵니다.
인쇄 대화상자에서 **배경 그래픽 켜기**, **머리글·바닥글 끄기**, **배율 100%**로 두세요.

## 남은 이슈

**60장 제한** — `backend/app/services/full_lecture_note.py`의 `_MAX_PAGES_IN_PROMPT = 60`
때문에 61장 이상인 강의는 뒷부분이 전체 정리본에 반영되지 않습니다.
69장짜리 강의로 확인했습니다.

**긴 슬라이드 잘림** — 인쇄 페이지 높이를 고정했기 때문에, 스크립트가 1,800자를 넘는
슬라이드는 오른쪽 칸 끝이 잘릴 수 있습니다. 9px까지 줄여도 한계입니다.
`globals.css`의 `.print-slide { height }`를 풀면 두 장으로 넘어가지만 빈 페이지가 늘어납니다.

**Python 3.11 이상 필요** — 3.9로 venv를 만들면 `storage.py:127`의 `dict | list` 문법에서
`TypeError`로 기동에 실패합니다.
